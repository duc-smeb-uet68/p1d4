Mục tiêu·

Repo chạy, kiến trúc rõ

Bạn có repo Day-3-Lab-Chatbot-vs-react-agent-E402 trên máy, môi trường sẵn sàng, hiểu vai trò từng thành phần và phân vai nhóm 5-6 người.

Fork, clone, cài môi trường

Mở repo Day-3-Lab-Chatbot-vs-react-agent-E402, bấm Fork rồi clone về máy theo hướng dẫn.

Cài môi trường:

cd Day-3-Lab-Chatbot-vs-react-agent-E402
python -m venv .venv
source .venv/bin/activate        # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env

Smoke test:

python src/app.py

Troubleshooting — Vấn đề thường gặp

python không tìm thấy / sai phiên bản → Mindset: Tách "Python nào đang chạy?" khỏi "Code đúng chưa?" — xác minh interpreter trước. → Thử python3 --version (cần ≥ 3.10).

Lỗi Font / Encoding tiếng Việt trên Windows Terminal → Code trong src/app.py đã tự động reconfigure sys.stdout sang utf-8.

ModuleNotFoundError khi chạy python src/app.py → Kiểm tra đã activate .venv chưa và đứng ở thư mục gốc repo chưa.
